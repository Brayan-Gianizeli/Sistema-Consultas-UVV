# Sistema de Consultas UVV

Sistema Web desenvolvido em C# com ASP.NET Core MVC para gerenciamento de usuários e consultas.

## Tecnologias utilizadas

- C#
- ASP.NET Core 8
- ASP.NET Core MVC
- Entity Framework Core
- SQL Server
- HTML e CSS

## Funcionalidades

- Cadastro de usuário
- Login e autenticação
- Cadastro de consultas
- Visualização de consultas
- Edição de consultas
- Exclusão de consultas
- Proteção das consultas para usuários autenticados

## Como executar o projeto

### 1. Clonar o repositório

```bash
git clone https://github.com/Brayan-Gianizeli/Sistema-Consultas-UVV.git
```

### 2. Abrir o projeto

Abra o arquivo `WebApplication1.sln` no Visual Studio.

### 3. Configurar o banco de dados

Verifique a Connection String no arquivo `appsettings.json`.

### 4. Criar o banco de dados

No Console do Gerenciador de Pacotes do Visual Studio, execute:

```powershell
Update-Database
```

### 5. Executar o projeto

Execute o projeto pelo Visual Studio.
